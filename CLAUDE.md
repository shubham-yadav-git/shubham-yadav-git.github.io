# shubhamy.in

Personal site of Shubham Yadav, an SDET. React 18 + Vite, one page, no router, no UI library.

## Commands

- `npm run dev` — local dev server
- `npm run build` — production build into `dist/`
- `npm run preview` — serve the built `dist/`
- `python3 scripts/update-blog.py` — refresh `src/data/blog.json` from the Hashnode RSS feed

There is no linter or test suite. Verify changes with `npm run build` and by looking at the page.

## Layout

- `index.html` — SEO meta, JSON-LD, Google Analytics, font links. Keep its descriptions in step with the page content.
- `src/App.jsx` — section order: Masthead → About → Resume → Skills → Blog → Contact → Footer
- `src/components/Section.jsx` — shared numbered section wrapper (`num`, `title`, optional `intro`)
- `src/components/*.jsx` — one file per section; content lives as constants at the top of each file
- `src/index.css` — the only stylesheet; design tokens on `:root`
- `src/data/blog.json` — generated by the feed script; imported at build time
- `public/` — copied verbatim to the site root (`CNAME`, `robots.txt`, `sitemap.xml`, `app-ads.txt`, icons)

## Deployment

GitHub Pages deploys from GitHub Actions (`.github/workflows/deploy.yml`), not from a branch.
Every push to `master` builds and publishes. A daily scheduled run refreshes the blog feed and redeploys.
Do not add a `gh-pages` branch or deploy script.

## Ground rules

- The site presents Shubham as a **test engineer and backend developer**. Lead with testing, quality, APIs, backend and infrastructure. Android apps and frontend work are deliberately left out.
- Don't rewrite the owner's copy unless asked. Restructuring and restyling are fine; changing what the text says is not.
- Follow the design system in `.claude/skills/site-design/SKILL.md` for any visual change.
- For editing resume entries, skills or contact details, see `.claude/skills/update-content/SKILL.md`.
- `.agents/tasks/` holds notes from an earlier Kiro rebuild. They are history, not current instructions. Its plan describes the old dark sidebar design and `gh-pages` deploy, both since replaced.
